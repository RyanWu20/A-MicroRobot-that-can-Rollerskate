# 小小白复刻指南（可落地版）

面向想从零做出一台「小小白」的人：按本指南备料、打印、装机、刷系统，再回到仓库根目录 [`README.md`](../README.md) 做软件部署与第一次走路。

> **依据说明**：型号优先取自本仓库源码与打印工程（见文末「证据来源」）。README 里写「主控板 / 总线舵机」的地方，本指南给出与代码匹配的具体料号与国内采购关键词。价格会波动，表中为 2026 年参考量级，仅供预算。

### 0.1 电脑环境：MacBook Pro M4 + Parallels Windows 11

你只有一台 **MacBook Pro M4**、外加 **Parallels 标准版里的 Windows 11** 时，完全可以完成复刻。原则是：**日常开发与刷头部固件优先用 macOS；舵机 Wizard / OpenRB 官方工具扫不稳时，再把 USB 设备交给 Win11 虚拟机。**

| 工作 | 在哪里做 | 说明 |
| :--- | :--- | :--- |
| 打开 / 切片 `小小白3D打印.3mf` | **macOS** | 装 [Bambu Studio](https://bambulab.com/zh-cn/download) 或 OrcaSlicer（均有 Apple Silicon 版） |
| 刷 Pi 镜像、改 `network-config` | **macOS** | [Raspberry Pi Imager](https://www.raspberrypi.com/software/) 有 Mac 版；读卡器插 Mac 即可 |
| SSH、`make setup` / `sync` / `run` / 健康检查 | **macOS** | Terminal + [Homebrew](https://brew.sh) 装 `git`、`make`；机器人在局域网里 |
| 头部固件 **第一次 USB 烧录** | **macOS（推荐）** | `brew install arduino-cli`，再装 ESP32 核心；串口是 `/dev/cu.usbmodem*`，**不是** Linux 文档里的 `/dev/ttyACM0` |
| 头部固件 **以后更新** | **macOS → 经 Pi** | 机器人装好后用 `make firmware-uart`，USB 不用再接到电脑 |
| Dynamixel Wizard 2 改舵机 ID | **先 macOS，不行再用 Win11** | App Store 有 **Universal（含 Apple Silicon）** 版；OpenRB 插 Mac 后在 Wizard 里选对应串口 |
| OpenRB 官方 Arduino 板支持包 / 个别 Windows-only 工具 | **Win11 虚拟机** | 用 Parallels 把 OpenRB **连接给 Windows** |
| 自行 `make image` 打包 SD 镜像 | **不要在 Mac / Win11 里做** | 需要原生 Linux 的 loop/qemu；请直接下 [Releases](https://github.com/RyanWu20/A-MicroRobot-that-can-Rollerskate/releases) 的 `xiaoxiaobai-*.img.xz` |
| 训练自己的 RL 策略 | **本机做不了** | 需要 NVIDIA GPU；复刻走路/滑板用仓库自带 ONNX 即可 |

**Parallels 标准版 USB 要点（M 系列 Mac 上的 Win11 是 ARM 版）**

1. 同一时刻只让 **一侧** 占用 USB：设备管理器里若 Mac 已打开该串口，Windows 会抢不到；反之亦然。用完 Wizard 后在 Parallels 菜单把设备改回「连接到 Mac」。
2. 插入 OpenRB / XIAO 后，点菜单 **设备 → USB**，选「连接到 Windows」。标准版支持按次连接；不必上 Pro。
3. 若设备进了 Win11 却没有 COM 口：OpenRB、XIAO 一般是 USB-CDC，多数情况免驱；仍没有时，可关机虚拟机后在「配置 → 硬件 → + → 串口」，把源选成 Mac 上的 `/dev/cu.usbmodem…`（把主机串口映射进虚拟机，常比直通 USB 更稳）。
4. **不要指望 Win11 ARM 里装 x86 专用 USB 驱动**；串口类设备优先用系统自带 CDC，或走上面的「串口映射」。
5. 烧录 XIAO 时若板子由机器人 5V 供电，先拔掉头部 5V 再插电脑 USB，避免双供电。

**macOS 第一次烧头部固件（示例）**

```bash
brew install arduino-cli
arduino-cli core update-index
arduino-cli core install esp32:esp32
# 插入 XIAO ESP32S3 Sense（必要时按住 Boot 再插）
ls /dev/cu.usbmodem*
cd <仓库>/xiaoxiaobai
make firmware-upload ESP32_PORT=/dev/cu.usbmodem1101   # 改成你 ls 看到的端口
```

若 `make firmware-upload` 报权限，把当前用户加入可访问串口的权限后重插线，或对设备文件确认未被「屏幕使用时间 / 安全软件」拦截。

**舵机配置在 Mac 上的推荐路径**

1. OpenRB 接好舵机供电与 USB，插 Mac（**不要**同时连接给 Win11）。
2. 打开 macOS 版 Dynamixel Wizard 2 → 选 OpenRB 对应端口 → 按 [§4](#4-舵机配置装机前完成) 改 ID / 1 Mbps / Return Delay=0。
3. 若 Mac 上扫描失败、端口灰掉：把 OpenRB **改连到 Win11**，装 Windows 版 Wizard 2 再扫；扫完把 USB 还回 Mac。

## 1. 系统长什么样（装机心智模型）

```
2S 18650 电池组 ──► OpenRB-150（舵机供电 + USB 转总线）──► 20× XL330 菊花链
                         ▲ USB
Raspberry Pi Zero 2 W ───┘
        │ I2C
        └─► BMI088 IMU
        │ UART 3 Mbaud
        └─► XIAO ESP32S3 Sense ── SPI ──► 2 寸 LCD
                         └─ I2S ──► 功放 + 扬声器
                         └─ 板载摄像头 / 麦克风
```

- 运动：Pi 上 50 Hz 跑 ONNX 策略，经 OpenRB 驱动舵机。
- 表情 / 语音 / 摄像头：头部 XIAO 协处理，经串口与 Pi 通信。
- 滑板：同一套机身，**换上打印好的滑轮鞋**后切滑板策略（见 README「使用教学」）。

**电源注意（必读）**

- 本项目与 microban 一样用 **2S（约 6.0–8.4 V）直接给 OpenRB / 舵机总线供电**，策略也在 5–8 V 域随机化下训练。
- ROBOTIS 手册给 XL330 的标称工作电压多为 **3.7–6.0 V**。2S 满电高于标称上限：务必使用可靠 BMS、保持代码里的过流保护、**不要长时间堵转**，并预留备用舵机。若你坚持严格按手册 6 V 供电，策略表现可能偏离训练分布，需要自行验证。
- Pi 必须吃 **稳定 5 V**，不要把 2S 电池直接接到 Pi 的 5V 脚。
- 头部板若由 Pi 的 5V 供电：用 USB 给 XIAO **烧录固件前先拔掉这根 5V**，避免双供电。

### 3.5 打印后处理

1. 去支撑、修轴承孔与舵机仓毛边，**先干装再上螺丝**。
2. 舵机仓过紧可轻微打磨；过松不要靠大力拧自攻硬扯。
3. 走线槽里的锐边倒一下，避免磨破舵机线。
4. 滑轮鞋：保证四轮同轴、转动灵活；装上后整机比赤脚 sole 抬高约 12.6 mm（仿真值）。

## 4. 舵机配置（装机前完成）

**建议在舵机外壳用油漆笔写上 ID**，装错腿会非常难查。仅有 Mac + Parallels 时，工具放哪边见 [§0.1](#01-电脑环境macbook-pro-m4--parallels-windows-11)。

1. 给 OpenRB-150 烧录厂商提供的 **USB ↔ Dynamixel** 桥接固件（按 ROBOTIS 文档；Arduino 板包若在 Mac 上不好装，改用 Win11 虚拟机）。
2. 安装 [Dynamixel Wizard 2](https://emanual.robotis.com/docs/en/software/dynamixel/dynamixel_wizard2/)（**优先 Mac App Store Universal 版**；不行再用 Windows 版）。
3. **每次只接一只舵机**（新舵机默认常为 57600 bps）。
4. 设置：**ID** 按下表、**Baud Rate = 1 Mbps**、**Return Delay Time = 0**，保存。
5. 装舵盘前转到中位：**Goal Position = 2048**，再按中立站姿装连接件。

| 关节 | 右侧 ID | 左侧 ID |
| :--- | :---: | :---: |
| 髋 yaw | 1 | 7 |
| 髋 roll | 8 | 2 |
| 髋 pitch | 9 | 3 |
| 膝 | 10 | 4 |
| 踝 pitch | 11 | 5 |
| 踝 roll | 12 | 6 |
| 肩 pitch | 13 | 16 |
| 肩 roll | 14 | 17 |
| 肘 | 15 | 18 |
| 头 yaw | 19 | |
| 头 pitch | 20 | |

ID ↔ 关节以 [`xiaoxiaobai/src/constants.py`](../xiaoxiaobai/src/constants.py) 的 `MOTOR_TO_ID` / `MOTOR_SIGN` 为准；接线布局不同时改这两张表即可。

## 5. 装配顺序（与 README 一致，强调易翻车点）

装配照片见 `docs/images/assembly_*.jpg`。

### 5.1 腿（先做一条练手）

顺序：髋 yaw 舵机 → 髋 → **髋部双舵机块**（roll + pitch）→ 大腿 → 膝 → 小腿 → **踝部双舵机块** → 脚。

- 双舵机块空间极紧：**先插好中间那根总线线，再把舵机推进去**。
- 髋、脚的从动侧装 **惰轮舵盘**。
- 线走大腿/小腿线槽，关节处留余量。
- 脚底可贴薄橡胶（走路用）。

### 5.2 躯干

- 骨盆：髋 yaw（ID 1、7）+ 轴承。
- 腰部连接骨盆与上半躯干。
- 上半躯干：肩 pitch（13、16）、头 yaw（19）+ 轴承。
- **Pi + BMI088 叠装在躯干一侧，IMU 必须拧死**；松动会直接导致走歪。
- 电池组居中放置，降低重心。

### 5.3 手臂 / 头部

- 臂：肩 pitch（在躯干上）→ 肩 → 肩 roll → 上臂 → 肘 → 前臂/手。
- 头：头 yaw（19）→ 脖子 → 头 pitch（20）→ 固定板 → LCD + XIAO + 喇叭 → 头壳。
- **XIAO 的 microSD 卡槽不要插卡**（与屏、串口脚冲突）。

### 5.4 接线

1. 舵机菊花链；躯干附近用一分二 / 一分三接到 OpenRB。
2. Pi USB → OpenRB。
3. Pi I2C（默认 bus 1）→ BMI088（注意 3.3 V 逻辑）。
4. Pi UART：GPIO14(TX)→ XIAO D9，GPIO15(RX)← XIAO D2，共地。
5. LCD / I2S 引脚表见根目录 README「组装说明 → 接线」。

> **警告**：舵机线同名对同名；接反电源可能永久性损坏舵机。焊点热缩或热熔胶绝缘。

### 5.5 上电前检查表

- [ ] 2S 电压、极性正确；BMS 已接通；开关能切断总电源  
- [ ] Pi 只吃 5 V 降压输出  
- [ ] 20 个舵机 ID 无重复，总线无短路  
- [ ] IMU 固定、排线有应变余量  
- [ ] 头部 5V 与 USB 烧录不会同时供电

## 6. 软件：从刷卡到第一次站立

细节命令以根目录 README「软件部署 / 使用教学」为准，这里只给复刻最短路径。**Mac 用户请整段都在 macOS 上做**（不要用 Win11 去 `make run`），固件端口见 §0.1。

1. 在仓库 [Releases](https://github.com/RyanWu20/A-MicroRobot-that-can-Rollerskate/releases) 下载 `xiaoxiaobai-*.img.xz`。**不要**在 Mac / Parallels 里跑 `make image`。
2. 在 Mac 上打开 Raspberry Pi Imager → 设备选 Zero 2 W → Use custom → **不要**再套一层系统定制。
3. 写完后把卡重新插入 Mac，打开 `bootfs` 卷，编辑 `network-config`，填入 **2.4 GHz** Wi-Fi（或之后用安卓 App 蓝牙配网）。
4. 默认用户 `user` / `password`，主机名 `xiaoxiaobai`；首次启动等分区扩展 1–2 分钟。
5. Mac 上配置 SSH 后进入 `xiaoxiaobai/`：第一次用 USB 烧头部  
   `make firmware-upload ESP32_PORT=/dev/cu.usbmodemXXXX`  
   （`XXXX` 以 `ls /dev/cu.usbmodem*` 为准；Linux 文档里的 `/dev/ttyACM0` 在 Mac 上不存在。）  
   之后改用 `make firmware-uart`，经 Pi 串口更新，不必再拆头接电脑。
6. 悬空吊起机器人后依次：`make voltage` → `make imu` → `make direction-check` → `make motor-check`。
7. `make run` → Web UI「站立」→「走跑」；**务必做 IMU 安装标定 + 手动 roll/pitch 校正**（README 专节，差 1° 就会走歪）。
8. 关机用 `make shutdown`，等 10–15 秒再拨电源。

滑板：换上滑轮鞋 → Web UI 切「滑板」策略（`skate_glide` / `skate_single_leg`）。

## 7. 常见问题

| 现象 | 优先排查 |
| :--- | :--- |
| 扫不到舵机 | 波特率是否已改 1 Mbps；OpenRB 供电；一次只接一只再并网 |
| Mac 上 Wizard 看不到端口 | 确认 USB 没被 Parallels 抢走；换线/口；或改连 Win11 再扫 |
| Win11 里有设备无 COM 口 | Win11 on ARM 驱动问题：改用「串口映射」或改回 macOS Wizard |
| `make firmware-upload` 找不到口 | Mac 上用 `/dev/cu.usbmodem*`；不要用 `/dev/ttyACM0` |
| `make image` 失败 | 预期行为：Mac/Win 不要打包镜像，改下 Releases |
| `make voltage` 缺 ID | 该腿分线虚焊、ID 写错、某只舵机没上电 |
| IMU 无数据 | I2C 接线、地址、`raspi-config` 是否开 I2C；模块是否 3.3 V |
| 能站会抖、走就倒 | **先做 IMU 标定/校正**；再查中位舵盘是否在 2048 装的；`MOTOR_SIGN` 是否反 |
| 一边沉 | 惰轮侧装配、脚底摩擦、电池是否居中、单腿螺丝是否对称 |
| 头部无表情 / 无麦 | 固件未烧；UART 交叉；XIAO 未上电；SD 槽误插卡 |
| 连不上 Wi-Fi | 是否 5 GHz；Zero 2 W 只支持 2.4 GHz |
| 滑板打滑或卡住 | 轮轴承、鞋是否卡脚、地面摩擦系数；策略是否切到滑板 |

## 8. 建议采购与装机日程

**第 1 周：下单 + 打印**

- 先下舵机与 OpenRB（货期最长）；同时在 Mac 上用 Bambu Studio 开打 5 盘件。
- 并行买 Pi、XIAO Sense、BMI088、屏、电源套装；备一只 USB-C 读卡器。
- 在 Mac 装好：Pi Imager、Bambu Studio、Homebrew、`arduino-cli`、Dynamixel Wizard 2；Win11 里备好 Wizard 作后备。

**第 2 周：配置 + 装配**

- 一天写完 20 只舵机 ID（Mac Wizard 优先，不通再切 Parallels）。
- 腿 → 躯干 → 臂 → 头 → 总线分线。
- 电源与 5 V 降压单独台上测再装机。

**第 3 周：软件与调校**

- Mac 上下 Releases 镜像并刷卡；USB 烧头部一次，其后用 `firmware-uart`。
- 健康检查与 IMU 校正到直线能走稳，再试广播体操 / 滑板。
