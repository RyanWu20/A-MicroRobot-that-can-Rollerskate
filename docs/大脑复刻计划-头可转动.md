### P0.1 Conda 环境（Mac）

上游 `xiaoxiaobai/pyproject.toml` 要求 **Python ≥3.12**。本机 mock 不必装 `spidev` 等 Linux 专用包。

```bash
conda create -n xiaoxiaobai python=3.12 -y
conda activate xiaoxiaobai
cd xiaoxiaobai

# 大脑阶段最小依赖（够 api-dev / 文字脑）
pip install "numpy" "pillow>=12.3.0" "websockets>=14" "onnxruntime>=1.26.0"

# 可选：本机文字脑
# brew install ollama && ollama pull qwen2.5:7b
```

## 风险与约束（全程盯住）

| 点 | 说明 |
| :--- | :--- |
| 两套「智能」别混 | 对话脑 = API/Omni/工具；`src/agents/*.onnx` = 腿/滑板策略 |
| Pi 不算力 | Pi Zero 不跑大 Omni / 大 VLM；多模态走云端 |
| 2S 与 XL330 | 手册标称约 3.7–6.0 V，本仓用 2S：可靠 BMS、勿长时间堵转、备一只舵机 |
| 烧录双供电 | 烧 XIAO 时必须拔掉机器人侧 5V |
| XIAO 卡槽 | microSD **不插卡**（与屏、串口脚冲突） |
| 身体工具 | 无腿前保持关闭运动工具；P4 后也只做转头相关，不要开走路 |
