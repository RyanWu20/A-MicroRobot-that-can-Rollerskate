# 小小白「大脑」复刻指南（头+躯干优先）

面向预算有限、想先做「能聊、能记、能看一眼」的人：先评估「只做大脑」是否成立，再按阶段在本机与少量硬件上落地。完整整机仍以 [`docs/复刻指南.md`](复刻指南.md) 与根目录 [`README.md`](../README.md) 为准。

> **结论先说**：你的方案**可以先做，且强烈推荐按阶段做**；但仓库里的「大脑」≈ **云端实时语音/文本 LLM + 本地工具（记忆/备忘/知识库/表情）+ 头部相机按需塞一帧**，**不是**可在本机训练的端到端 VLA。`src/agents/*.onnx` 是**走路/滑板 RL 策略**，不是聊天 Agent。

## 0. 方案评估（先读这段）

### 0.1 你的目标 vs 仓库实际能力

| 你的预期 | 仓库能做到的 | 缺口 |
| :--- | :--- | :--- |
| 实时聊天 | ✅ 文字聊天（OpenAI 兼容 API / 本机 Ollama）+ 语音实时对话（千问 Omni Realtime） | 语音依赖云端 Key 与网络；Pi Zero 2 W 上不跑大模型 |
| 记住任务 / 执行任务 | ✅ 长期记忆、对话检索、备忘录、本地知识库；可选 WorkBuddy 让电脑干活；可调表情/提示音 | 「走路 / 挥手 / 广播体操」等身体工具需要腿臂舵机；大脑阶段应关掉或接受失败 |
| VLM（看一眼再说） | ✅ 语音里听到「看见了什么 / 看看…」时拍 **1 帧 JPEG** 发给 Omni | 不是持续视频理解；不是多模态微调训练管线 |
| VLA（看图直接控身） | ❌ 本仓库**没有**视觉-语言-动作端到端策略 | 腿策略吃的是 IMU/本体感觉，不是摄像头；要做 VLA 等于另开研究项目 |
| 买几块硬件 / 本机先训起来 | ✅ **本机立刻**可 `make api-dev`；Mac M4 可跑 Ollama 做文本脑 | 「训练」二字易混：本仓可训的是 **MuJoCo 里走路 ONNX**（要 NVIDIA GPU），**不是**聊天脑；大脑不用训，接 API 即可 |

### 0.2 仓库里两套「智能」别混

```
┌─────────────────────────────────────────────────────────────┐
│  A. 对话脑（你要的「大脑」）                                   │
│     Web UI / 语音 → LLM 或 Qwen-Omni → 工具调用               │
│     记忆 memory.json · 备忘 · 知识库 ·（可选）动作工具          │
│     证据：xiaoxiaobai/src/api/{chat,llm,memory,knowledge}.py │
│           xiaoxiaobai/src/voice_chat.py（OMNI_MODEL=…）      │
└─────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────┐
│  B. 运动策略（整机才需要）                                     │
│     src/agents/*.onnx → 50 Hz 控腿/滑板                       │
│     证据：constants.py 的 WALK_AGENTS；README「策略模型」       │
│     与聊天记忆无关；名字里的 agent = RL policy 文件名           │
└─────────────────────────────────────────────────────────────┘
```

### 0.3 「只装大脑 + 躯干」是否可行

| 层次 | 可行性 | 说明 |
| :--- | :---: | :--- |
| **阶段 0：零硬件** | ✅ | Mac 上 `make api-dev`，浏览器聊文字、配 LLM、玩记忆/备忘/知识库（mock 无真麦真屏） |
| **阶段 1：桌面头脑** | ✅ | Pi + XIAO Sense + LCD + 功放喇叭；USB 供电即可；不装舵机也能实时语音 + 看一眼 |
| **阶段 2：头壳 + 上半躯干打印件** | ✅ | 外形与主控固定；仍可不装 OpenRB / 腿臂舵机 |
| **阶段 2b：头 yaw/pitch 两只舵机** | 可选 | 需要 OpenRB + 2× XL330（ID 19/20）才能转头；对话不依赖转头 |
| **阶段 3：补腿臂做成整机** | 延后 | 才解锁走路工具与 ONNX；预算大头在这里 |

**总评**：先做大脑在工程上**正确且省钱**；请把预期从「本机训出 VLA」改成「云端 Omni 实时听/说 + 按需一帧 VLM + 本地工具记忆」。若以后要真 VLA，应另选栈（数据集、大算力、新策略网络），不要指望现成 `agents/*.onnx`。

### 0.4 粗算：大脑路径比整机省多少

| 方案 | 电子约计 | 代打结构约计 | 相对整机 |
| :--- | ---: | ---: | :--- |
| 整机（[`复刻指南`](复刻指南.md) §2.5） | ¥5,500–7,500 | ¥250–800 | 基准 |
| **大脑桌面台架（阶段 1，无打印）** | **¥280–450** | ¥0 | 约 **1/15～1/20** |
| **头壳 + 上半躯干（阶段 2，无舵机）** | 同上 + 电源件 | ¥80–250（只打头/躯干相关件） | 约 **1/10～1/15** |
| **再加头 2 舵机（阶段 2b）** | +¥580–760（OpenRB+2×XL330） | 同左 | 仍远低于整机 |

整机最贵的是 **20× XL330**；大脑路径默认不买它们。

## 1. 软件：对话脑能做什么、怎么实现

### 1.1 能力清单（大脑阶段可兑现）

| 能力 | 实现方式 | 本机 mock | 有头部硬件 |
| :--- | :--- | :---: | :---: |
| 文字聊天 + 人设 | `api/chat.py` + `api/llm.py`（多厂商 / Ollama） | ✅ | ✅ |
| 长期记忆增删查 | `MemoryStore` → `~/.config` 下 `memory.json`；工具 `memory_save` / `memory_search` | ✅ | ✅ |
| 对话回忆 | `ConversationStore` + 关键词检索（非向量库） | ✅ | ✅ |
| 备忘录 / 提醒 | `memo_*` 工具；可推到脸屏清单 | ✅（无屏则仅逻辑） | ✅ |
| 本地知识库 | `knowledge.py` 分词检索上传文档 | ✅ | ✅ |
| 联网搜索 | 千问原生 search 或 `web_search` 工具 | ✅（有 Key） | ✅ |
| 表情 / 提示音 | `robot_set_expression` / `robot_play_sound` | mock | ✅ |
| 实时语音 | `voice_chat.py`：`qwen3.8-omni-flash-realtime`（+ 可选 TTS） | 有限（mock 无真麦） | ✅ |
| 看一眼（VLM-lite） | 听到视觉词 → 抓 1 帧 → `input_image_buffer.append` | ❌ 需相机 | ✅ |
| WorkBuddy 电脑任务 | `computer_task` 工具 | ✅（需装 WorkBuddy） | ✅ |
| 走路 / 手势 / 滑板 | `robot_walk` / `robot_gesture` / … | mock 装样子 | 无腿臂则失败 |

### 1.2 实时语音与「看」的细节（证据）

- 模型：`OMNI_MODEL = "qwen3.8-omni-flash-realtime"`（`xiaoxiaobai/src/voice_chat.py`）。
- 路径：麦/喇叭/相机在 **XIAO**；Pi 配 session；也可走 Pi 路由。
- 视觉：**一问一帧**，固件与 Python 侧用「看见 / 看看…」一类词触发；不是每秒推流给模型。
- Key：`$DASHSCOPE_API_KEY` 或 `make voice-key` 写入的配置文件；文字 LLM 可与语音共用千问 Key，也可单独配 Ollama。

### 1.3 阶段 0：本机立刻开始（MacBook Pro M4 足够）

在仓库的 `xiaoxiaobai/` 目录：

```bash
# 依赖按 xiaoxiaobai/README 用 uv；然后：
make api-dev
# 浏览器打开终端提示的地址（默认 :8000）
```

建议顺序：

1. Web UI → LLM：先配 **Ollama**（`http://127.0.0.1:11434/v1`，如 `qwen2.5:7b`）验证文字脑与工具；或配百炼 / DeepSeek 等。
2. 打开记忆、备忘、知识库，用文字多轮验证「记住 / 想起 / 记事」。
3. 申请阿里云百炼或千问平台 Key → `make voice-key`（或环境变量）→ 真机阶段再开语音；mock 下语音仅为占位。
4. **不要**在大脑阶段去训 `mjlab_xiaoxiaobai`：那是腿策略，与聊天无关，且 Mac 无 NVIDIA 训不了官方栈。

关闭身体工具（有硬件但无腿时）：在 LLM / 语音相关设置里关掉 `allow_motion_tools` / `voice_motion`（见 `chat.py` 对配置项的读取），避免模型乱调走路。

### 1.4 你预期的「VLA/VLM 大脑」怎么对齐

| 说法 | 本指南建议 |
| :--- | :--- |
| 「实时聊天 + VLM」 | ✅ 用 Omni + 相机一帧；阶段 1 就能对齐预期 |
| 「VLA 大脑」 | ⚠️ 改称「工具调用驱动表情/（将来）关节」；端到端 VLA 不在本仓范围 |
| 「本机训练大脑」 | ❌ 对话用 API/Ollama 推理即可；没有官方「训聊天脑」脚本 |
| 「agents 帮它记任务」 | ✅ 记任务靠 **memory/memo 工具**；`agents/*.onnx` 只管腿 |

## 2. 硬件：只做大脑时买什么、装什么

### 2.1 系统边界（大脑台架）

```
USB 5V 电源（台架）──► Raspberry Pi Zero 2 W
                           │ UART 3 Mbaud
                           └─► XIAO ESP32S3 Sense ── SPI ──► 2 寸 LCD
                                            └─ I2S ──► 功放 + 扬声器
                                            └─ 板载摄像头 / 麦克风

（暂不接）OpenRB / XL330 / BMI088 / 2S 电池组
```

与整机差异：用 **USB 稳定 5V** 喂 Pi（及头部 5V），不必先上 2S 电池与 BMS；没有舵机总线。

### 2.2 阶段 1 BOM（桌面能聊）

| 物料 | 数量 | 型号要点 | 参考价 |
| :--- | :---: | :--- | ---: |
| 主控 | 1 | **Raspberry Pi Zero 2 W**（带排针） | ¥120–200 |
| microSD | 1 | ≥16 GB，建议 32 GB A1/A2 | ¥20–40 |
| 头部板 | 1 | **Seeed XIAO ESP32S3 Sense** | ¥90–130 |
| 表情屏 | 1 | **2 寸 320×240 SPI LCD**（ST7789 类） | ¥25–45 |
| 功放 | 1 | **MAX98357A** I2S | ¥8–15 |
| 扬声器 | 1 | 约 **35×25 mm** | ¥5–15 |
| USB 供电 | 1 | 5V ≥2A 给 Pi；XIAO 可由 Pi 5V 供电（烧录前拔掉） | ¥20–40 |
| 杜邦线 / 排针 | 若干 | UART、SPI、I2S、5V/GND | ¥10–20 |

**明确不买（大脑阶段）**：18～20 只腿臂舵机、BMI088（无走路策略）、滑轮鞋、整套 2S 大电流 BMS（台架 USB 即可）。

### 2.3 阶段 2：打印「头 + 躯干」哪些件

从 [`hardware/小小白3D打印.3mf`](../hardware/小小白3D打印.3mf) 里**只要**：

| 需要 | 可缓 / 不要 |
| :--- | :--- |
| 头壳、脖子、头部固定板 | 腿、脚、髋、踝、滑轮鞋 |
| 上半躯干（装主控固定件） | 前臂/手、肩臂全套（除非你想空壳好看） |
| 主控板固定件、后盖（若方便走线） | 第 3 盘滑轮鞋整盘 |
| 可选：骨盆/腰（只为立住上身） | 第 5 盘里纯腿部高密度件 |

代打话术可改成：「只要头壳、脖子、头部固定板、上半躯干、主控固定/后盖；腿臂滑板全部不要。」配色仍可用整机指南里已选定的**赛博**方案，只点上述零件颜色。

轴承：无头舵机时，头 yaw 轴承可先不装或用螺丝临时固定；装 2 舵机转头时再买 Φ22×4 薄壁轴承（头 yaw）。

### 2.4 阶段 2b（可选）：头能转

| 物料 | 数量 | 说明 |
| :--- | :---: | :--- |
| OpenRB-150 | 1 | 总线适配 |
| XL330-M288-T | 2 | ID **19** 头 yaw、**20** 头 pitch（见整机指南舵机表） |
| 惰轮舵盘等 | 按头结构 | 与整机头部装配一致 |

供电：两只舵机仍建议按整机用 **2S → OpenRB**；不要用 Pi 的 5V 硬扛总线。若暂时只 USB 台架，可先不装舵机，避免供电纠缠。

### 2.5 接线（与整机相同的子集）

1. Pi UART：GPIO14(TX)→ XIAO **D9**，GPIO15(RX)← XIAO **D2**，共地。  
2. LCD / I2S 引脚：根目录 README「组装说明 → 接线」。  
3. **XIAO 的 microSD 卡槽不要插卡**（与屏、串口脚冲突）。  
4. 烧 XIAO 固件时：拔掉机器人侧 5V，只留电脑 USB-C。  
5. 第一次固件：`make firmware-upload ESP32_PORT=/dev/cu.usbmodem…`（Mac）；之后 `make firmware-uart`。

Mac + Parallels 分工与整机指南 [§0.1](复刻指南.md#01-电脑环境macbook-pro-m4--parallels-windows-11) 相同；大脑阶段通常**用不到** Win11 / Wizard（无舵机时）。

### 2.6 软件装到 Pi 上（阶段 1）

1. 下 [Releases](https://github.com/RyanWu20/A-MicroRobot-that-can-Rollerskate/releases) 的 `xiaoxiaobai-*.img.xz`，用 Raspberry Pi Imager 刷卡；在 Mac 上改 `network-config`。  
2. SSH 进 Pi → `make setup` / `make run`（或 `api-enable`）。  
3. 浏览器打开 `http://<机器人IP>:8000/`，配语音 Key 与 LLM。  
4. `make camera` 确认画面；再开语音会话，说「看看前面有什么」验证一帧 VLM。  
5. 无舵机时：运动页 / 走路命令预期失败或跳过；以聊天、记忆、表情、语音为准。

## 3. 推荐节奏

| 顺序 | 做什么 | 验收 |
| :--- | :--- | :--- |
| **本周** | `make api-dev` + Ollama 或云端文本 LLM | 文字多轮；`memory_save` 后再问能想起 |
| **等快递** | 下单阶段 1 BOM；并行询价头/躯干代打 | 物料到齐清单打钩 |
| **台架一周** | 刷镜像、烧头部、UART、屏、喇叭 | 实时语音通；「看看…」能根据画面答 |
| **外壳** | 只装头+上躯干；USB 或简易 5V | 桌面摆件形态稳定对话 |
| **以后有预算** | 再买舵机/IMU/电池走整机指南 | 解锁走路与手势工具 |

## 4. 常见误解

| 误解 | 实情 |
| :--- | :--- |
| `src/agents` 是 LLM Agent | 是 **ONNX 步态/滑板文件** |
| 有摄像头 = 已具备 VLA | 仅有 **按需一帧的 VLM 问答** |
| Pi Zero 2 W 可本地跑 Omni / 大 VLM | 语音多模态走**云端**；本地最多 Ollama 小文本模型（更建议在 Mac 上跑 Ollama，Pi 只做机器人端） |
| 大脑阶段必须 OpenRB + IMU | **否**；对话链路是 Pi ↔ XIAO |
| 先训再聊 | **先接 API 再聊**；训练属于整机运动线 |
